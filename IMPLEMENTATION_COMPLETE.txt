================================================================================
HOW TO RUN
================================================================================

1. Prepare data:
   - Place Fantasia files: data/fantasia/Y1.txt to Y5.txt, O1.txt to O5.txt
   - Place CHF files: data/chf/chf01_rr.txt to chf05_rr.txt
   
   OR run: setup_data  (downloads automatically)

2. Execute analysis:
   In MATLAB, from the matlab/ directory:
   
   >> main
   
   Expected runtime: 2-5 minutes (depending on Monte Carlo trials)

3. View results:
   - Open fig00_unified_dashboard.png in image viewer
   - Load analysis_workspace.mat in MATLAB
   - Examine CSV files in matlab/results/
   - Read documentation in docs/

================================================================================
KEY DESIGN DECISIONS
================================================================================

✓ UNIFIED WINDOW DISPLAY
  - Single comprehensive figure instead of separate windows
  - 3×2 tiled layout for optimal information density
  - All plots visible simultaneously for cross-reference

✓ MONTE CARLO FRAMEWORK
  - 50 trials per SNR level (fast execution)
  - 4 SNR levels from high (30 dB) to low (5 dB) SNR
  - Physiological bounds maintained (300-2000 ms RR)

✓ DYNAMIC ADAPTATION
  - 50-beat rolling window for variance (captures local patterns)
  - Linear variance-to-parameter mapping (interpretable)
  - Inverse relationship for alpha (high variance → lower alpha)

✓ BACKWARD COMPATIBILITY
  - Individual PNG files still generated for legacy code
  - All original CSV outputs preserved
  - Original functions unchanged
